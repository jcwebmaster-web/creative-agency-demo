
# JC Studio — Creative Agency Demo

A responsive creative agency website built with HTML, CSS, JavaScript, and PHP. This project demonstrates modern website layout, responsive design, interactive navigation, portfolio cards, and a functional contact form.

## Live Demo

**Website:** https://jcstudio.jarishcastaneda.com/

## Features

- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- Hero, services, about, and portfolio sections
- CSS animations and scroll reveal effects
- Contact form with client-side and server-side validation
- PHP email handling
- Success and error feedback for form submissions

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- Git and GitHub
- Hostinger hosting

## Local Development

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or copy this project into the `htdocs` directory.
3. Create your local `config.php` using `config.example.php` as a reference.
4. Configure the email settings in `config.php`.
5. Start Apache from the XAMPP Control Panel.
6. Open `http://localhost/creative-agency-demo/` in your browser.

The local contact form test confirms form processing only. Actual email delivery requires a configured mail service.

## Contact Form Configuration

The `config.example.php` file provides placeholder configuration values.

Create your own `config.php` with the appropriate recipient and sender email addresses. Do not commit `config.php` or publish private credentials.
